# 敵の特殊行動・状態異常・治療

画面の配置は維持し、既存の行動・治療呪文の選択肢を拡張した。

## ROMデータと確認した処理

Wiz1日本版のモンスター構造体からタイプ（+0x40）、ブレス属性（+0x65）、属性抵抗（+0x67）を追加抽出する。特殊フラグ（+0x68）は石化0x01、毒0x02、麻痺0x04、逃走0x20、仲間呼び0x40。0x10はカティノへの補正であり、眠らせる打撃能力ではない。

地下1階の主グループID0〜5には魔術師/僧侶呪文・ブレス・毒/麻痺/石化の能力はない。逃走可能な敵は存在する。地下2階からゾンビの麻痺、クリーピングクラッドの毒、レベル1メイジ/プリーストの呪文などが登場する。原作にない能力を地下1階の敵へ付与しない。

日本版固定バンク `$DC84`〜`$DCDA` の呪文選択を確認した。魔術師系、次に僧侶系を判定し、該当タイプなら確実、それ以外なら乱数下位2ビットが非0の時に選択する。呪文レベルは敵グループ共通で、`[0,生存数+2)` の抽選結果が1なら減少し、0になる場合は1に戻してその詠唱を中止する。使用レベルの降下判定は乱数バイト179以上の間繰り返す。最後に85未満かどうかで同レベルの2枠から選ぶ。

呪文表はCPU `$DD10` と `$DD20`。行動コードから `(コード/2)-1` で抽出済み呪文IDを求める。日本版の実テーブルをHTMLへ同梱する。

`python tools/verify_enemy_actions.py` はタイプ4通り×両系統レベル各8通り×乱数バイト8通り×範囲乱数3通り×生存数3通りの18,432ケースをROMと照合し、選択コードと使用後のグループレベルが一致した。乱数呼び出し境界で値を固定する検証で、ROMとブラウザーの乱数系列の一致を主張しない。結果は `output/enemy_actions/verification.json`。

## 戦闘へ接続した行動

- 呪文選択→ブレス→仲間呼び→逃走→通常攻撃の順に判定する。敵の行動・対象はターン開始時に決める。
- ハリト・バディオス：ROMの効果定数1d8を単体へ適用。
- カティノ：正常なパーティメンバーへ睡眠判定。検証済みのWiz1レベル差式を使う。装備による魔法抵抗はまだ0として扱う。全員が眠っても敗北にせず、待機ターンを実行できる。
- ブレス：属性が非0なら乱数バイト153未満で選択。実行時点の現在HP/2を切り捨て、各生存メンバーへ適用。運勢・属性抵抗による軽減は未接続。
- 敵の逃走：該当フラグがあり、正常な敵の合計レベルが行動可能なパーティの合計レベル未満なら、乱数バイト166未満で選択。逃げた敵から経験値を得ない。全員が逃げた場合は戦闘を終了する。倒した敵と逃げた敵が混在する場合は倒した敵の経験値のみ分配する。
- 通常攻撃が1回以上命中し対象が生きている場合、毒・麻痺・石化のフラグを処理する。毒は別フラグ、麻痺は状態3、石化は状態4。睡眠など正常以外の状態では敵の通常攻撃ダメージを2倍にする。

未対応の呪文は選択された名前と「効果未実装」をログに出す。仲間呼びもログだけで増援は作らない。高位呪文・ドレイン・クリティカル・タイプ別打撃防御・後衛への射程補正・先制は未接続。これらを通常攻撃へ偽装していない。

参考にした米国版資料：[敵の行動](https://taotao54321.github.io/appsouko/work/Game/Wiz1_NES/battle_enemy_act.html)、[敵の打撃](https://taotao54321.github.io/appsouko/work/Game/Wiz1_NES/battle_fight_enemy.html)、[ブレス](https://taotao54321.github.io/appsouko/work/Game/Wiz1_NES/battle_breath.html)。日本版の呪文選択と定数は実ROMの命令列・テーブルで確認している。

## 暫定部分

毒・麻痺・石化の付与率は各25%の試作値。原作の運勢値・属性抵抗の再計算を接続するまでの代用であり、ROMの追加効果確率とは異なる。毒は成功した歩行1回と継続中の戦闘ターン末に各1HPを減らし、0HPで死亡する。睡眠はターン末に25%で解除する。これらの頻度・回復率も試作値で画面に明記する。ブレス・攻撃呪文のセーブ/耐性軽減はまだ行わない。

全員が睡眠ならターンを進められるが、全生存者が麻痺・石化なら行動不能として戦闘を終える。開発用の入口帰還・全回復で再開可能。全回復は原作の寺院・蘇生とは別機能。

## 治療と保存

既存の選択欄にディアルコとラツモフィスを追加。ディアルコは睡眠・恐怖・麻痺（状態1〜3）を0へ、ラツモフィスは毒を0へ戻す。ディアルコで石化・死亡は治らない。戦闘中は指示として予約し、探索中は即時実行できる。回数は僧侶系に各2回を与える試作仕様で、原作の習得レベルを再現したものではない。

残り回数は `magic.dialko` / `magic.latumofis` に保存する。古い記録では欠けた2項目を職業に応じた初期値で補完する。HP・状態・毒も保存対象で、不正記録は復元前に拒否する。効果本体の既存CPU照合については `docs/status_rules.md` を参照。

`node tests/check_enemy_actions.cjs` は呪文選択18,432入力をPythonとJSで比較し、睡眠判定625入力を既存Python実装と比較する。さらに敵の呪文・睡眠/待機/回復・実行時HPによるブレス・敵の逃走・打撃後の毒/麻痺・治療・歩行中の毒死・保存移行を確認する。`check_encounter_ui.cjs` は既存の画面から治療を選び、表示と保存へ反映されることを確認する。実ブラウザーの見た目は未検証。

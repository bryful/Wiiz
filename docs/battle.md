# 探索版の試作戦闘

地下1〜10階を歩くと、各階のROM出現テーブルに基づく敵の主グループと遭遇する。詳しくは [encounters.md](encounters.md)。探索画面の「スライムと戦う」では従来どおり単体との試験もできる。各メンバーへ攻撃・呪文・防御・逃走を指示し、「ターン実行」で敵味方の行動を処理する。詳しくは [turns.md](turns.md)。勝利・逃走・全滅で探索操作を再開できる。戦闘中の移動・編成・装備変更・保存・読み込みは禁止する。

ROMから直接読む値は、モンスター全101体の名前・出現数ダイス・HPダイス・AC・攻撃ダイス・レベル・経験値。画像は既存のROM抽出PNGをデータURLとしてHTMLに埋め込む。味方の攻撃は既存の装備寄与を含む暫定値を使う。

次の処理は原作の再現ではなく試作ルール。

- 歩行遭遇の頻度は試作ルール。全10階の主グループを実装し、追加グループ・特殊遭遇は未接続。
- 行動順は日本版ROMと照合した素早さ補正・乱数の式を使う。通常攻撃の命中・職業/レベル/力の補正も日本版ROMと照合した式を使う。敵攻撃のAC参照不具合は再現せず対象の防具ACを使う。詳しくは [combat.md](combat.md)。敵の一部呪文・ブレス・状態異常を接続したが、確率・軽減などに暫定部分がある。詳しくは [enemy-actions.md](enemy-actions.md)。隊列による射程は未実装。
- 逃走成功率65%。失敗すると敵が反撃する。
- HPはダイスで決め、0になると倒れる。味方は死亡状態になる。経験値は勝利時の行動可能な生存者で等分し、端数切り捨て。
- 戦闘終了後のHP・状態・経験値は通常の保存対象。戦闘そのものは保存しない。
- 入口・地上の「試作用の全回復」で参加メンバーのHP・状態・毒をリセットできる。原作の宿屋・寺院・蘇生費用の代用であり原作仕様ではない。

## 基本呪文

ROMの抽出済み呪文定義を使い、ハリト（HALITO、敵単体1d8ダメージ）とディオス（DIOS、仲間単体1d8回復・最大HPで制限）を接続した。ディオスで死亡者は回復しない。探索中もディオスを使える。

使用回数・習得は試作。魔術師系にハリト2回、僧侶系にディオス2回を与え、全回復で補充する。戦闘中は詠唱を術者の指示として設定し、他の味方・敵の行動と合わせて処理する。ハリトの魔法抵抗・属性抵抗は未接続。原作のレベル別呪文回数や習得処理の再現ではない。

残り回数はキャラクターの `magic.halito` / `magic.dios` として保存する。以前のversion 2記録でmagicがない場合は職業別初期回数を補完する。不正な回数はパーティ全体の復元前に拒否する。入力された元の保存オブジェクトを変更せずに補完する。

実装：`web/explorer/battle.js`。`engine.js`が現在のパーティを参照する形で接続し、`ui.js`が戦闘結果とキャラクター表示を同時に更新する。

検証：`node tests/check_battle.cjs`、`node tests/check_encounters.cjs`、`node tests/check_encounter_ui.cjs`、`node tests/check_explorer_ui.cjs`、既存の探索・パーティUIテスト。ROM由来の相手・画像、経験値の重複付与防止、逃走成功・失敗、死亡・全滅、戦闘中の操作制限、回復・保存復元・呪文消費と旧記録補完を確認。描画とイベントはNode VM上のモックで確認し、実ブラウザー表示は未検証。

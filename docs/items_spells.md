# アイテム・呪文テーブル

2026-10-21：保存済みの解析HTMLと関連データは`reference/`でGit管理しています（パスはリポジトリ直下基準）。以下の生成・検証コマンドは従来どおり`output/`へ出力します。

対象は `rom_profiles.py` に登録済みの日本FC版3リビジョンのみ。ファイル位置はiNESヘッダー16バイトを含む。名前・値は各ROMから抽出し、参考サイトの一覧は転記していない。

## 出力と再生成

`python tools/analyze_roms.py --verify` で、各作品の `items_spells/` に `data.json`、検索用 `index.html`、`verification.json` を作る。単独では `python tools/extract_item_spells.py .nes/WIZ3.NES --output output/wiz3/items_spells`。

|作品|アイテム|呪文|アイテム構造|
|---|---:|---:|---|
|I|101|50|0x10110から64バイト固定長|
|II|110|50|0x10010のポインター表、61バイトレコード|
|III|138|53|0x10010から31バイト固定長|

IIは先頭ポインターの位置から表の容量を推定すると129件になるが、有効IDの上限は110件。原作の上限判定（`CMP #$6E`）と店舗初期化の終端を確認し、後続の文字列領域をアイテムとして読まない。

## フィールド

Iは英語未鑑定名・鑑定名の各長さと16文字領域が先頭34バイト。日本語名はbank2のCPU B000/B0CAのポインターからFF終端まで読む。IIは英語16文字、日本語16文字、未鑑定名ポインター2バイト、その後27バイト。IIIは鑑定・未鑑定名の2ポインター4バイト、その後27バイト。IIIの文字列は英語NUL・日本語NULの組。

以下は名前領域を除いた統計領域内のオフセット。Iのみ統計領域30バイト。

|項目|I|II|III|
|---|---|---|---|
|種類 / 属性 / 呪い / SP / 破損パラメータ / 変化先|0..5|0..5|0..5|
|価格（6バイトpacked BCD）|6..11|6..11|6..11|
|初期在庫|12|別領域・未抽出|別領域・未抽出|
|使用呪文|13|12|12|
|装備職業ビット列|14|13|13|
|回復値|15|14|14|
|AC改善値|16|15|18|
|攻撃力|17|16|19|
|ダイス個数 / 面数 / 加算|19 / 20 / 21|18 / 17 / 19|21 / 20 / 22|
|最低攻撃回数|18|20|23|
|クリティカル|22|21|24|

ACは改善値の符号を反転し、装備後のACに加える `ac_modifier` とした。職業ビットは下位から戦士・魔術師・僧侶・盗賊・司教・侍・君主・忍者。IIIの攻撃力以降はbank13 B266の装備処理でも位置を確認。村正は3作品とも10d5、侍専用になる。

II/IIIの使用呪文は下位6ビットがID、上位2ビットは使用場面のフラグ。0は使用効果なし。IはFFが使用効果なし。作品ごとにIDは異なる。属性・SP・破損・未解読の耐性等は生値を保持する。破損値を確率の百分率として扱わない。

名前内の合字of、薬・巻物の絵文字は表示文字に展開する。元の名前コード配列も保存する。

## 呪文

I/IIは魔術師21・僧侶29、IIIは魔術師24・僧侶29。IIIにはメリト・ツザリク・ラダルトが加わり、各レベルの境界も異なる。

|作品|レベル境界表|戦闘ハンドラー表|
|---|---|---|
|I|0x1EF94（両系統が境界21を共有）|0xA404|
|II|0x1A9AC|0x18D56|
|III|0x1AE6C|0x18D1E|

呪文名とレベルは全件抽出。効果はハンドラーの位置を全件保持し、一部の攻撃呪文についてダメージ処理に渡されるダイス定数と属性生値を抽出した。静的に抽出した定数は、実際のダメージ結果・対象範囲・成功率を保証しない。例えばジルワンの特殊な大きなダイス定数も丸めず記録する。未解析効果を0ダメージとしない。Iのみ使用場面と選択対象コードも抽出し、選択対象と実際の効果範囲は区別する。

## 検証範囲

`verify_item_spells.py` はpy65で原作コードを実行する。

- I: D0B5アイテム読み込みを日英202ケース、D083呪文名読み込みを日英100ケース照合。
- II: C9E0アイテムポインター110件とレコード全バイト、8D35呪文ディスパッチ50件を照合。
- III: EE93アイテムポインター138件とレコード全バイト、8D09呪文ディスパッチ53件を照合。

合計653ケース。読み込み／参照先の一致であり、全フィールドの意味や戦闘効果の再現まで検証したものではない。II/IIIの名前表示ルーチンは未照合。

`python -m unittest discover -s tests` は原作コードとの照合に加え、作品間で配置を混同しやすい村正・防具AC・IIIの追加呪文を検査。`node tests/check_item_spell_ui.cjs` は生成HTMLの実スクリプトをオフラインで実行し、名前検索、呪文切り替え、系統フィルター、空結果を確認する。ブラウザーでの見た目の検証は含まない。

AC呪文30件・基本回復呪文9件、SPの一部効果、装備済み1品の計算を追加解析し、共通JSONと独立したPythonルール実装に追加した。詳細と追加の検証範囲は [game_rules.md](game_rules.md) を参照。残る未確定フィールドを確定したルールとして使わない。

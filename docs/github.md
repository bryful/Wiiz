# 公開リポジトリの管理

Wiizはソースコード公開用のpublicリポジトリです。ダウンロードは[Wiiz_app](https://github.com/bryful/Wiiz_app)をご利用ください。

ソース、テスト、開発資料、第三者コードと必要なライセンス・出典を管理します。
ROM、ROMを埋め込んだHTML、抽出画像・音声などのreference生成物、sample画像、セーブ、ステート、output、署名鍵、認証情報、IDE個人設定は公開しません。
第三者のライセンス・著作権表示・出典・パッチは保持します。

更新時はgit add後にステージ対象を確認し、秘密情報・ROM・個人データの混入がないことを確認してコミットしてください。
